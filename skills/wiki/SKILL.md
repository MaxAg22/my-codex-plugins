Load $basics first when invoked on its own.

The project owns its wiki: its location, structure, and content. It records folder conventions, technology usage, patterns, and known pitfalls. No global conventions are supplied.

Keep one index listing all entries and what each covers. Read the index first, then only the entries relevant to the task.

If the wiki or its location and structure are undefined, ask the user to define them and wait. If a convention needed for the task is missing, ask and wait. Do not invent rules or adopt the original author's conventions.

Report what the relevant entries say and check dated technical facts against current documentation when needed. This skill reads the wiki; it does not write it.
