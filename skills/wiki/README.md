# Project wiki

The wiki holds the project's technology knowledge and development conventions:

- Folder structure, file organization, and naming conventions.
- How to use libraries, frameworks, tools, and platforms.
- Frontend patterns for components, page layout, forms, lists, styling, and interactions.
- Testing patterns and conventions.
- Known pitfalls and technical limitations.

Project documentation explains the product and system. Invariants state the rules every change must respect. The wiki explains how the project uses its technologies.

Each project defines its wiki's location, structure, and content. Keep one index listing all entries and what each covers. Skills consult that index and read the entries relevant to the task.

If the wiki is undefined or a required convention is missing, the agent asks the user and waits. It does not invent conventions.
